# 🌌 Python Creative Graphics

**A collection of generative art, creative experiments and visualizations created with Python.**

This repository is a growing collection of Python projects that turn code into visual art.

From spiral galaxies and cosmic starfields to colorful patterns and mathematical designs – each project explores the creative possibilities of Python through programming, mathematics and a little bit of randomness.

The goal is simple: experiment, create and have fun with code.

---

## 🎨 Gallery

### 01 – Spiral Galaxy

A procedurally generated spiral galaxy created with Python's built-in `turtle` graphics module.

The galaxy consists of randomly distributed stars, cosmic dust, four spiral arms and a glowing golden core. Colors are generated using the HSV color model, while mathematical functions determine the shape and distribution of the particles.

**Features:**
- Four spiral arms
- Randomized particle distribution
- Color gradients from gold to pink, purple and blue
- Glowing galactic core
- Starfield background

**Technologies:** `Python`, `Turtle`, `Math`, `Colorsys`, `Random`

## 🚀 Getting Started

### Requirements

- Python 3.x
- Tkinter (usually included with standard Python installations)

No additional Python packages are required for the current projects.

### Running an artwork

Clone this repository:

```bash
git clone https://github.com/YOUR-USERNAME/Python-Creative-Graphics.git
```

Navigate into the project directory:

```bash
cd Python-Creative-Graphics
```

Run an individual artwork:

```bash
python 01_spiral_galaxy.py
```

Each script runs independently. Simply choose the artwork you want to explore.
